linekit

模組化、跨框架的 LINE 服務開發工具包。
開始使用 GitHub
模組化
只需安裝你需要的：Core、Messaging 或 Login。
型別安全
完全使用 TypeScript 構建，提供卓越的開發體驗。
框架無關
支援 Express、Fastify、Next.js 或標準 Fetch API。

安裝

npm install @linekit/core @linekit/messaging @linekit/adapters-express

快速範例

import { createLineApp } from "@linekit/core";
import { lineMiddleware } from "@linekit/express";

const line = createLineApp({ /* credentials */ });

app.post("/webhook", 
  lineMiddleware(config),
  line.router({
    message: async (ctx) => {
      await ctx.replyText("哈囉！這是來自 linekit 的訊息！");
    }
  })
);
