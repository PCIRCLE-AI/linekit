linekit

A modular, framework-agnostic toolkit for LINE services.
Get Started View on GitHub
Modular
Install only what you need: Core, Messaging, or Login.
Type-Safe
Built with TypeScript for a superior developer experience.
Agnostic
Works with Express, Fastify, Next.js, or standard Fetch.

Installation

npm install @linekit/core @linekit/messaging @linekit/adapters-express

Quick Example

import { createLineApp } from "@linekit/core";
import { lineMiddleware } from "@linekit/express";

const line = createLineApp({ /* credentials */ });

app.post("/webhook", 
  lineMiddleware(config),
  line.router({
    message: async (ctx) => {
      await ctx.replyText("Hello from linekit!");
    }
  })
);
